# Routel Solutions and Consults Ltd

Company website for Routel Solutions and Consults Ltd, covering solar, networking, surveillance, and ongoing support.

## Run locally

This is a static website. From the project folder, run:

```powershell
py -m http.server 8000
```

Then open <http://localhost:8000>.

## Deploy with GitHub Pages

1. Push this project to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

GitHub Pages serves the HTML, CSS, JavaScript, and image assets directly; no build step is needed.
